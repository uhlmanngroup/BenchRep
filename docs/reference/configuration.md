# Overrides and config helpers

Import these classes and functions from `benchrep`. Overrides replace complete config sections; `update_config()` replaces individual existing fields in a config object. For examples, see [Configure workflows](../guides/configure-workflows/index.md).

    options:
      heading_level: 2

::: benchrep.PredictionOverrides
    options:

::: benchrep.EvaluationOverrides

      heading_level: 2

::: benchrep.update_config
    options:
      heading_level: 2
