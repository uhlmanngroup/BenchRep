# Reference

Look up the functions, configuration fields, contracts, and implementations used to configure, run, and extend BenchRep. For explanations of their behavior and relationships, see [Understanding BenchRep](../understanding/index.md).

- **[Workflow entrypoints](workflows.md):** launch training, prediction, or evaluation and inspect their arguments.
- **[Overrides and config helpers](configuration.md):** replace config sections, supply runtime objects, update fields, and load or save YAML.
- **[Configuration schemas](schemas/index.md):** look up accepted fields, nested sections, defaults, and validation requirements.
- **[Configuration wizards](wizards.md):** launch a browser editor and use its returned configuration and overrides.
- **[Results and statuses](results.md):** inspect workflow results, output paths, operation outcomes, and interruptions.
- **[Registries and discovery](registries.md):** find components, inspect their contracts, and register external implementations.
- **[Extension interfaces](interfaces.md):** implement compatible datasets, architectures, losses, metrics, models, and datamodules.
- **[Component catalogue](components.md):** find registered names and aliases, then inspect built-in constructors, forward methods, and model behavior.
- **[Example and artifact helpers](helpers.md):** locate packaged examples, prepare AnnData inputs, read or write artifacts, and export model graphs.
